خلاصه حرفه‌ای

مهندس ارشد فرانت‌اند / فول‌استک با بیش از ۵ سال تجربه در اپلیکیشن‌های سازمانی بهداشت و درمان و تجارت الکترونیک. در PharmaBits (نرم‌افزار گردش کار داروخانه برای بازار اروپا)، تمرکز عمیق روی Angular (۱۳–۱۹)، RxJS و NgRx با افزایش مشارکت عملی در ASP.NET Core، EF Core و Clean Architecture. در تنظیم استاندارد فنی تحویل فرانت‌اند—آمادگی مرج، بازبینی و قراردادها—مشارکت دارد و مستقیماً در پیاده‌سازی بک‌اند همکاری می‌کند (بدون نقش رسمی تیم‌لید). تحویل UI با عملکرد بالا و تست قوی؛ کار در کل استک با SOLID و همکاری قوی.

شهریور ۱۴۰۱ – تاکنون

Apoteek Logistiek (APL)

  • تحویل قابلیت‌های ماژولار Angular برای جریان موجودی و نسخه در محصول Apoteek Logistiek با NgRx، کامپوننت‌های standalone و معماری lazy-loaded.
  • همکاری در پیاده‌سازی ASP.NET Core—قابلیت‌ها، endpointها و مدل‌سازی—فراتر از مصرف API در UI؛ دسترسی داده به سبک repository برای گردش کار دارویی با الزامات حوزه تنظیم‌گری.
  • مالکیت گردش کار مرج و یکپارچگی فنی در پروژه‌های فرانت‌اند: بازبینی، gateهای یکپارچه‌سازی و قراردادهای مشترک (SCO مشارکت‌کننده فردی؛ نه مدیر تیم رسمی).
  • بهبود ابزار عملیاتی زنده با مقیاس‌دهی نقشه Leaflet.js به بیش از ۱۰ هزار مارکر همزمان از طریق تکه‌بندی reactive در RxJS و به‌روزرسانی کارآمد.
  • تقویت کیفیت با بیش از ۳۰۰ تست واحد و E2E (Jasmine/Karma، Cypress) و مشارکت در اهداف پوشش بالای ۸۰٪ در ماژول‌های حساس.

فناوری‌ها: Angular 13–19, RxJS, NgRx, standalone components, ASP.NET Core, EF Core patterns, Leaflet.js, Cypress, Jasmine, Karma, REST API

مهارت‌های فنی

فرانت‌اند

فریم‌ورک‌ها: Angular 13–19 (اصلی)، React.js، Next.js، Ionic.

مدیریت state: RxJS (پیشرفته)، NgRx، Zustand، Redux Toolkit، Context API.

معماری: NX Monorepo، میکروفرانت‌اند (Module Federation)، کامپوننت‌های standalone، lazy loading.

استایل و UI: Tailwind CSS، Sass/SCSS، Angular Material، PrimeNG.

بک‌اند

هسته: .NET 8/9، ASP.NET Core، C#.

ORM و داده: Entity Framework Core (Code First)، SQL Server، الگوی Repository، Unit of Work.

معماری: Clean Architecture، طراحی RESTful API، احراز هویت JWT، Identity Framework.

ابزار: Swagger/OpenAPI، Postman، Docker.

تست و DevOps

تست: Cypress (E2E)، Jasmine و Karma (واحد)، MS Test.

محیط: macOS (گردش کار بهینه برای M4)، Git، خطوط CI/CD، Vite، Webpack.

نقاط قوت اصلی

  • ذهنیت مهندسی: بهره‌گیری از مدل‌سازی ریاضی در سطح کارشناسی ارشد و منطق کنترل سیستم در معماری نرم‌افزار.
  • گردش کار مدرن: توسعه مبتنی بر macOS با گردش کار Git/CLI منظم و ابزارهای کمکی هوش مصنوعی برای بازنویسی سریع‌تر، بازبینی و تولید تست.
  • کد تمیز: تعهد به SOLID، DRY و الگوهای طراحی قابل نگهداری.
